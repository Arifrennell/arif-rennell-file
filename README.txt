ARIF RENNELL COMPLETE WEBSITE PACKAGE

Includes:
- index.html: updated homepage with SEO metadata, course section, guides and existing MEGA resource links.
- course.html: course overview page connected to the existing Rennell Software Masterclass website.
- sitemap.xml: lists the homepage and course overview page.
- robots.txt: permits crawling and points to the sitemap.

Publish using GitHub on mobile:
1. Open https://github.com/arifrennell/arif-rennell-file
2. Back up the current index.html before replacing it.
3. Upload/replace index.html and add course.html, sitemap.xml and robots.txt in the repository root.
4. Commit the changes.
5. After GitHub Pages publishes, check:
   https://arifrennell.github.io/arif-rennell-file/
   https://arifrennell.github.io/arif-rennell-file/course.html
6. In Google Search Console > Sitemaps, submit: sitemap.xml
7. Inspect the homepage and course.html URLs. Request indexing once if available.
