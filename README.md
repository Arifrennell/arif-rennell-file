# Arif Rennell — Official File Download Page

This repository hosts the official **Arif Rennell** file download page.

## Live URL
After publishing, your GitHub Pages site will be available at:
https://arifrennell.github.io/arif-rennell-file/

## Deployment Steps

### Step 1: Create a repository
1. Go to [GitHub](https://github.com) → click **New repository**.
2. Name it `arif-rennell-file`.
3. Keep it **Public** → Click **Create repository**.

### Step 2: Upload files
- Click **Add file → Upload files**.
- Upload `index.html` and `README.md` from this ZIP.
- Commit changes.

### Step 3: Enable GitHub Pages
1. Go to **Settings → Pages**.
2. Source → Branch: **main**, Folder: **/ (root)** → Save.
3. Wait 1-2 minutes for the live URL.

### Step 4: Update index.html (optional but recommended)
- Open `index.html` in GitHub editor.
- Make sure canonical URL, og:url, and JSON-LD URL match your live page:
  https://arifrennell.github.io/arif-rennell-file/

### Step 5: Optional SEO Boost
- Rename your MEGA file to `Arif_Rennell_File.pdf`.
- Share your GitHub Pages URL publicly.
- Use Google Search Console → Request indexing.
